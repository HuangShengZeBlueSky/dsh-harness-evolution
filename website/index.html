Method

One candidate can change both ends of a repair.

In ALFWorld, one handler records an accepted action in episode state. Other handlers use that state to guide the next prompt or check the next action. Evaluating those edits together lets their combined effect count toward selection.

Observe

Run the parent on a training batch. Sample successful and failed trajectories.

Propose

The improver reads the parent source, runtime interfaces and prior feedback, then returns one scoped edit.

Compare

Pair parent and candidate by task, trial and seed. Measure score changes, repairs, regressions and hook outputs.

Retain

Require a training gain, a changed hook output and, where used, nondecreasing validation performance.

What did the search actually change?

ALFWorld

From a tool receipt to the next action

After the environment accepts an action, the action-hint plugin records what changed. Context assembly and the pre-execution guard can then act on the same episode state.

Read the implementation ↗Inspect the evaluation ↗

DBBench

From a SQL result to an answer

The result bridge parses SQL receipts into arguments for the final answer. A separate write-workflow plugin tracks database changes across calls.

Read the implementation ↗Inspect the evaluation ↗

WebShop

Keeping track of product options

The option ledger tracks visible option evidence as the agent moves through a product page. The checkpoint also includes search-evidence and the helper modules used by both plugins.

OSBench

A skill can be the retained change

The runtime inserts the retained filesystem instructions during prompt assembly. The composition returns an empty list of executable mechanisms in this checkpoint.

Reproduction

Start with one round.

From a fresh checkout, run the synthetic A/B/C check with Python 3.10–3.12 and Node.js 22.19+ with npm. It exercises the real plugin runtime using a scripted actor.

python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e evolution
python evolution/scripts/smoke.py ./runs/smoke

The reproduction guide lists the external assets and model access for each benchmark. Choose a frozen profile to evaluate a released checkpoint, or an A/B/C profile to run a new search.
